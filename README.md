# Perancangan Jaringan Lokal dengan Cisco Packet Tracer

## Deskripsi
Proyek ini merupakan simulasi jaringan LAN menggunakan Cisco Packet Tracer dengan layanan HTTP dan DNS untuk mengakses website melalui nama domain.

## Perangkat
- 1 Router
- 1 Switch
- 1 Access Point
- 3 PC (2 kabel dan 1 nirkabel)
- 1 Laptop
- 1 Server

## Konfigurasi Jaringan
- Network: 192.168.1.x
- Gateway: 192.168.1.1
- IP Server: 192.168.1.6
- DNS Server: 192.168.1.6
- Domain: ikhsanjuli-profile.id

## Layanan
- HTTP: Aktif
- DNS: Aktif
- DNS Record: ikhsanjuli-profile.id mengarah ke 192.168.1.6

## Cara Pengujian
1. Buka IkhsanJ_20261320011.pkt di Cisco Packet Tracer.
2. Pastikan seluruh perangkat terhubung, dapat dites dengan ping/PDU antar perangkat.
3. Periksa konfigurasi IP dan layanan HTTP serta DNS.
4. Buka Web Browser pada PC yang terhubung ke switch.
5. Akses http://ikhsanjuli-profile.id.
6. Pastikan halaman website berhasil ditampilkan.
